## What Code Buster provides

<CardGrid stagger>
  <Card title="Repository structure" icon="seti:folder">
    Inspect dependency wiring, package cycles, module boundaries, clusters, and paths between files.
  </Card>
  <Card title="Actionable findings" icon="magnifier">
    Find dead code, duplication, complexity, unsafe patterns, feature flags, and architecture violations with source evidence.
  </Card>
  <Card title="Quality workflows" icon="approve-check-circle">
    Produce scores, quality gates, remediation plans, review views, and stable machine-readable reports for CI.
  </Card>
  <Card title="Multi-language analysis" icon="document">
    Analyze Dart, C-family languages, Java, Go, JavaScript/TypeScript, Python, Lua, Nim, SQL, HTML, CSS, and Wren in one repository.
  </Card>
</CardGrid>
